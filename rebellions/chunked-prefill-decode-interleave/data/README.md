# 측정 데이터

- workloads/: 두 정책에 동일하게 재생한 입력과 도착 시각.
- results/injection-*/: 핵심 단일 주입 실험.

warmup-* 원시 기록은 공유 자료에서 삭제했습니다. 실험에서는 동시 요청 1~4개와
prefill/decode 간섭을 워밍업한 뒤 본 측정을 수행했습니다.
본 측정의 validation.json에는 측정 중 추가 컴파일 발생 여부가 남아 있습니다.

Pilot 원시 결과는 포함하지 않습니다. 주입 시점 선정 방법은 루트 README, 설정은 metadata/pilot-settings.json을 참조하세요.
